# P1 跨页收尾回归清单 2026-07-05

## 0. 目的
用于 P1 收尾阶段的固定回归，不再凭感觉验收，而是按统一清单逐页核：
- 主标题是否先被看见
- 默认密度是否过重
- 模式切换是否顺
- 星币口径是否一致

---

## 1. 页面顺序
按以下顺序逐页回归：
1. Home
2. List
3. Detail
4. Space
5. Review

---

## 2. 逐页检查项
## 2.1 Home
- 主标题是否先于品牌壳层进入视线。
- 主推进卡是否仍然是首屏最强动作区。
- 愿望瓶与“最近发生 / 下一步往哪里靠”是否默认信息量适中。
- 是否存在重复解释同一件事的区块。

## 2.2 List
- `晨光，选 1 件推进` 是否仍是最先被读到的标题。
- 搜索与筛选入口是否不抢列表主任务。
- 条目主值 / 副值 / 右侧状态位是否统一，且不再出现信息重复。
- 默认列表长度下是否仍可快速扫读。

## 2.3 Detail
- 愿望标题是否是页面绝对主标题。
- `推进与记录 / 整理与设置` 切换是否语义清楚。
- 首屏星币信息条是否只表达当前真实有效的两件事：
  - 已入账
  - 剩余可得
- 不再出现旧模型残留词：
  - 可领取（详情页星币语境）
  - 待收取
  - 未入账
- 最近记录、推进区、低频工具区是否层级清楚。

## 2.4 Space
- 顶部 hero 是否已退到辅助位置，不再抢奖励中心主任务。
- `领奖与兑换 / 整理与工具` 是否一眼能理解为主切换。
- 行动态默认信息是否足够短：
  - 手里星币
  - 奖池词条
  - 现在可领
- 管理态是否只承担编辑与工具，不再混入“对方只读奖池”等旧分支。

## 2.5 Review
- `2026-07 的月度记录` 是否承担主标题。
- 热力图 + 内联摘要是否能在 10 秒内讲清这一期发生了什么。
- 次级区块默认是否收敛：
  - 留言默认只展示前 4 条
  - 完本默认只展示前 3 本
- 各 metric 下是否仍有重复解释或空态重复。
- 领奖统计是否清楚区分：
  - 次数
  - 花费

---

## 3. 跨页统一检查项
## 3.1 标题层级
- 品牌壳层 `人生愿望清单` 不应压过页面自身主标题。
- 页面主标题必须在首屏一眼被识别。
- 次级标题只承担分区说明，不抢主任务层级。

## 3.2 默认密度
- 首屏默认不摊开所有低频信息。
- 长列表默认裁切，按需展开。
- 空态文案不重复讲同一句话。

## 3.3 模式切换
- Settings 和 WishDetail 的双态切换不应造成迷路。
- 切到管理态后，必须清楚如何回到行动态。
- 其他页面不强行增加页面级双态切换器。

---

## 4. 星币一致性回归
结合 [docs/star-coin-consistency-regression-2026-07-05.md](docs/star-coin-consistency-regression-2026-07-05.md) 一起使用。

最低必测：
1. 回顾页 `星币 / 年 / 当前成员` 的期末余额 = 空间页 `手里星币`
2. 空间页 `现在可领` 数量在推进、回退、领奖后三态变化正确
3. 详情页 `已入账 / 剩余可得` 与共享 selector 输出一致
4. 领奖统计里的 `次数 / 花费` 不会被误读成单一进度
