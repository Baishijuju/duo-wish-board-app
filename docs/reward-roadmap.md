# 奖励系统路线

## 第一阶段：提前存入星星

状态：已实现。

范围：
- 奖励仍然只属于个人，不能替别人推进或领取。
- 用户可以把手里的星星币提前存入自己的奖励。
- 存入会扣减当前可用星星币，并记录为 `reward_deposit` 流水。
- 奖励存满后才允许领取。
- 领取记录为 `premium_redeem`，不再重复扣星星币。
- 同一奖励领取后，会消费一轮已存金额；如果要再次领取，需要重新存满。

云端依赖：
- `202606080000_reward_claim_kind_values.sql`
- `202606080001_star_coin_wish_rewards.sql`
- `202606080002_reward_deposits.sql`

## 第二阶段：奖励助力

状态：已实现。

范围：
- 成员可以把自己的星星币存入对方的星币奖励。
- 助力存入会扣减出资人的可用星星币。
- 奖励进度按同一奖励条目汇总所有人的存入。
- 奖励存满后，仍然只有奖励归属人可以领取。
- 领取后会消费一轮已存金额；再次领取需要重新存满。

暂不包含：
- 不支持撤回助力。
- 不单独展示每个人对同一奖励的贡献明细。

## 第三阶段：共同奖励

状态：已实现。

范围：
- 星币奖励可以设置为个人奖励或共同奖励。
- 共同奖励显示在双方的领奖区。
- 双方都可以往共同奖励里存入自己的星星币。
- 共同奖励存满后，任一空间成员都可以领取。
- 领取后会消费一轮已存金额；再次领取需要重新存满。

暂不包含：
- 不要求双方都确认后才能领取。
- 不展示个人贡献明细。
- 不支持把已存在的个人奖励批量转换为共同奖励；需要逐条编辑。
